Build Custom In-Game Pipelines

Generate assets at runtime or integrate directly into internal level editors using our low-latency REST API, WebSocket streams, and official Python / Node.js packages.

  • ✓ Webhook Delivery: Asynchronous callback notifications when 4K batch renders finish.
  • ✓ Model Context Protocol (MCP): Integrate with Claude Desktop or cursor agents.
  • ✓ Fine-Tuning API: Programmatically upload image datasets and trigger training jobs.
POST /v1/generate 
// Generate 3D Mesh with PBR Texture Maps
const response = await fetch("https://api.scenario.com/v1/generate/3d", {
  method: "POST",
  headers: {
    "Authorization": "Bearer sc_live_apiKey",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    modelId: "mod_fantasy_assets_v2",
    prompt: "Dragon scale war shield, engraved runes, gold trim",
    format: "gltf",
    polycount: 12000,
    maps: ["albedo", "normal", "roughness", "metallic"]
  })
});

const data = await response.json();
console.log("Model URL:", data.assetUrl);
